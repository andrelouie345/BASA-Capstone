====== EOSY assessments ======
===== Event =====
The End of School Year round for CRLA and Phil-IRI.

===== Required =====
* EOSY is open (**Home → Round calendar**).
* You downloaded the latest data.

===== What to do in BASA Tutor =====
The same as BOSY ([[:Functions:CRLA|CRLA]], [[:Functions:Phil-IRI|Phil-IRI]]).

===== Steps =====
[ ] Download the latest data before you start.
[ ] Run CRLA EOSY (Grades 1-3) and Phil-IRI EOSY (Grades 4-10).
[ ] Check **Home → Reminders** for learners not yet assessed.
[ ] Send your work when connected, and check that it was approved.
