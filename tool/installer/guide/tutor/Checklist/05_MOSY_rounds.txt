====== MOSY rounds ======
===== Event =====
The Middle of School Year rounds: CRLA MOSY (one round) and Phil-IRI MOSY #1, #2 and #3.

===== Required =====
* The round is open (**Home → Round calendar**).
* You downloaded the latest data.

===== What to do in BASA Tutor =====
The same as BOSY ([[:Functions:CRLA|CRLA]], [[:Functions:Phil-IRI|Phil-IRI]]). Phil-IRI gives each learner a passage they haven't read before.

===== Steps =====
[ ] Download the latest data before you start.
[ ] Grades 1-3: run CRLA MOSY (**Assess → CRLA by section**, round MOSY).
[ ] Grades 4-10: run the Phil-IRI MOSY round (**Assess → Phil-IRI by section**).
[ ] Check **Home → Reminders** for learners not yet assessed.
[ ] Send your work when connected.
[ ] Repeat for MOSY #2 and MOSY #3 of Phil-IRI.
