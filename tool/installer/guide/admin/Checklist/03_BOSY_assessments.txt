====== BOSY assessments ======
===== Event =====
The Beginning of School Year round. CRLA for Grades 1-3; Phil-IRI (English) for Grades 4-10: the Group Screening Test (GST) first, then the individual reading for learners who need it //(to confirm with ma)//.

===== Who =====
* **Tutors** assess their sections' learners.
* **Coordinator** follows the progress, reviews uploads and finalizes Phil-IRI.

===== Required =====
* The BOSY round is open in the Round calendar.
* Each tutor has downloaded the latest data (assessing works offline after that).
* For CRLA Grade 1-3 stories: the region's stories are in BASA (Region X is seeded).

===== What to do in BASA =====
Tutors enter results as they assess ([[:Functions:CRLA|CRLA]], [[:Functions:Phil-IRI|Phil-IRI]]). They send their work when they are connected; you approve it ([[:Functions:Getting and sending data|Review uploads]]). Follow the progress on the dashboard and in [[:Functions:Reports|Progress monitoring]]. When a section's Phil-IRI round is done, finalize it ([[:Functions:Phil-IRI|Finalize]]).

===== Steps =====
[ ] Check **Home → Round calendar**: BOSY is //open// for CRLA and Phil-IRI.
[ ] Remind tutors to download the latest data before they assess.
[ ] Grades 1-3: tutors run CRLA (**Assess → CRLA by section**) for each learner, in the languages the grade takes.
[ ] Grades 4-10: tutors record the GST (**Assess → Group Screening Test**), then run the Phil-IRI sessions (**Assess → Phil-IRI by section**) for the learners who need one.
[ ] Every few days, open **Sync → Review uploads** and approve the tutors' uploads, or reject one with a reason the tutor will read.
[ ] Open **Home → Reminders** to see which sections still have learners not assessed.
[ ] Open **Reports → Progress monitoring** for BOSY. A section counts as done when it reaches the done threshold.
[ ] When a section's BOSY Phil-IRI is complete, open **Assess → Finalize** and finalize it.
[ ] Optional: export each Grade 1-3 section's CRLA scoresheet (**Assess → Scoresheet export**) with the blank DepEd CRLA2 file.
