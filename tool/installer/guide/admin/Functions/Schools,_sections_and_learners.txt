====== Schools, sections and learners ======
===== Schools =====
**Learners → Schools**. The superadmin adds, edits and removes schools (DepEd school ID, name, region, division). Everyone else sees their own school.

===== Sections =====
**Learners → Sections**. A section is a grade, a name and a school year. Admins and coordinators add, edit and remove their school's sections; tutors see the sections they are assigned to. The grade is a number (1 to 10).

===== SF1 import =====
**Manage → SF1 import** (on a computer). Reads a section's DepEd SF1 Excel file into BASA: the section and its learners.
1. Pick the file.
2. Check the column list (which column holds the LRN, names, sex, birth date, ...). It is saved for next time.
3. Run the trial: BASA shows what it would import, without saving.
4. Import.
5. If a learner already in BASA has different details, BASA lists a conflict: keep the details in BASA or update them from the file.
6. **Check the count**: //Inserted// plus //Already enrolled// should equal the number of learners on the SF1. If it is lower, some rows were skipped: look at the skipped rows in the trial.
You can only import your own school's files. The import saves to the server at once (it needs a connection), so it is not "unsent work": **Delete unsent work and download** does not undo it.

==== "This file wasn't read correctly" ====
BASA refuses an SF1 when a cell holds unreadable characters (it names the row and column). Open the file in Excel, **Save As → Excel Workbook (.xlsx)**, and import that file.

==== SF1s imported from .xls before this version ====
Before this version, BASA could misread a long //.xls// SF1 (the old Excel format): a learner's name came out garbled and the learners after it were skipped without a message. If you imported an //.xls// SF1 with an older BASA, import the same file again now: learners already in BASA show as //Already enrolled//, and the missing ones are added. Then check the count (step 6).

===== Learners and roster CSV =====
**Learners → Learners**. Pick a section to see its learners (search by name or LRN). Save the section's roster as a CSV file with the download button. In the admin build, open a learner to see their history.

===== Learner history =====
**Manage → Learner history**. One learner's record by school year: section, CRLA profile per round and language, Phil-IRI results, ARAL (class, tutor, attendance, check-ins) and Summer Remediation. Find the learner by section and name, or type their LRN. It shows what is on this device: download the latest data first.
