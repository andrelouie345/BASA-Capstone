# [admin]          Strings from admin-only METHODS. Checked on the scan builds
#                  (BASA_SCAN_BUILD: console commands compiled in, so every method
#                  a build can call is in it): each must be in the admin scan
#                  build (proves it is spelled right and survives compilation)
#                  and NOT in the tutor scan build. When you add an admin-only
#                  method or file, add one string from it: a refusal message or a
#                  server function name, never text in a comment (comments are
#                  not compiled). Never a migration name: lib/core/release.dart
#                  lists every migration and is in BOTH builds, and Dart keeps
#                  one copy of equal strings (sf1_transfer_in leaked that way,
#                  2026-11-16; test/tool/scan_markers_test.dart checks it).

#                  builds: in the admin build, not in the tutor build. (Shipped
#                  builds call no ViewModel method until the screens exist, so
#                  method strings can't be checked there yet.)

#                  builds: in neither.
